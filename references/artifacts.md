# Artifacts and checking

Read this before building a diagram, plot, HTML page, or video.

## Pick the format

| Reader's task | Starting point |
| --- | --- |
| Assess an answer or recommendation | Concise prose with decisive reasons and conditions |
| Compare values or options | Table for exact values; plot for patterns or uncertainty |
| Understand relationships or a mechanism | Labeled diagram with a brief explanation |
| Explore cases or vary assumptions | Interactive page with useful defaults and reversible controls |
| Understand change over time | Keyframes; animation or video when motion materially helps |

- Add a simple overview diagram when it saves the reader effort. Combine formats only when they explain different aspects.
- An artifact can be large, custom, and single-use. Build one when it saves the reader effort, not by default.
- Without rendering tools, give a text or static alternative. Keep exact machine-output schemas unchanged.
- Prefer reproducible diagrams and plots for precision. Mark hand-drawn or generated illustrations as schematic, and mark invented numbers as illustrative next to the figure.
- Put labels beside what they explain. Give each visual one takeaway. Give each control a purpose, show its current setting, and add a reset.

## Video

Use only when a video tool is available and the user agrees. Ask before using paid APIs or keys; suggest local or free narration. Provide pause, replay or stepping, captions, and a transcript. Respect reduced-motion settings.

## HTML

Without an existing stack, use one self-contained file that opens directly. Use semantic structure, keyboard controls, visible focus, and a readable layout. Give a text equivalent for essential visual information and pair color with labels.

## Checking

- Label simulations and their assumptions. Never present illustrative values as measurements or invented confidence scores as evidence.
- Before delivering, check displayed values against sources. When tools allow, inspect the rendering and try the key interactions. State each check you did not do.
