# Presentation findings

2026-10-14. The retained preview uses Rich 15.0.0 and wcwidth 0.9.2 with pinned development dependencies. It is a separate renderer, not native Claude Code or Codex UI integration.

## Reproducible checks

The audit covers 96 conditions: two languages × four report layouts × three widths × four styles. All preserve their own source content, fit the requested width, and keep ANSI/plain text and wrapping identical. All 24 D conditions keep sample identifiers and the copy command contiguous. Across all variants, 84/96 conditions preserve those tokens contiguously; the remaining cases split the inline command across lines.

Eight safeguard tests cover complete emphasis spans, retained negation/conditions, bold-only evidence, explicit color roles, quoted/code text, invalid or ambiguous selections, and monochrome fallback. These check application of selected highlights, not the model's semantic judgment.

The audit is generated by `preview.sh --audit`; raw output is not shipped. A/B/C share wording within each language. D retains the report's facts but changes wording and hierarchy; source-content preservation is not a factual-equivalence test.

## Reader guidance

The reader requested a combination of grouped explanation, selective emphasis, and parallel bullets at one information level. Important messages and short subtitles should stand out; explanatory and repeated text stays plain. This is adopted in the skill and optional cores.

The reader also preferred a reordered Chinese CUDA answer in one unblinded, untimed comparison. That packet and its generated render outputs were retired after the decision. Its combined changes do not establish the individual benefits of colors, bold, ordering, or length. The [evaluation summary](../SUMMARY.md) preserves the decision and limits.

Native interface readability, font fallback, visual contrast, clipboard behavior, timed comprehension, and current-version cross-model behavior remain unverified. No global configuration was changed.
